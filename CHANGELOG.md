- *(api)* Rewrite LocalizeDir trait with non-panicking core - New trait methods:
  - `try_to_localized_dir(locale) -> Option<&Dir>` (non-panicking     primitive)
  - `to_localized_dir(locale)` (panicking, honors `fallback`)
  - `available_locales()`, `has_locale(locale)`, `fallback_locale()`
  - `base_path()`, `parent_folder()`, `dir_name()`, `full_path(locale)`
The macro now embeds the whole base directory exactly once via a single `include_dir!` and navigates it at runtime, instead of expanding `include_dir!` per (variant, locale) pair. This keeps compile times flat as the template tree grows.

### Refactor

- *(macros)* Extract attribute parsing into args module - Implements `syn::parse::Parse` for `#[localizedir(...)]`: one positional `LitStr` base path plus optional `fallback`, `parent`, `case` key/value pairs. Rejects unknown keys, duplicate keys, non-literal values, and tolerates trailing commas. Fully unit-tested without a compiler context.
- *(macros)* Extract filesystem discovery into its own module - Handles `$VAR` interpolation (mirroring `include_dir!` semantics), anchors relative paths against `$CARGO_MANIFEST_DIR` so the macro works inside cargo workspaces, discovers locale subdirectories (filtering `.hidden`, `_partials`, `node_modules`, `target`), and validates that every `(locale, variant)` directory exists. Injectable env lookup keeps tests hermetic.
- *(macros)* Extract code generation into expand module - Pure `(DeriveInput, Args) -> syn::Result<TokenStream>` function. Validates the input (enum, non-generic, unit variants only), resolves parent folder + per-variant directory names, anchors the base path, validates the filesystem, and emits the inherent `LOCALIZEDIR_BASE` static plus the `LocalizeDir` trait impl. Generates the optional fallback override only when configured.
- *(macros)* Reduce lib.rs to a thin proc-macro facade - The 280-line monolith is replaced by a 46-line entry point that parses the attribute and the item, then delegates to `expand::expand`. All errors flow through `syn::Error::into_compile_error` so diagnostics point at the offending token instead of surfacing as `proc-macro panicked`.
- *(macros)* Extract naming conventions into naming module - Replaces the buggy hand-rolled `pascal_to_snake_case` (which mangled `APIResponseDirs` into `a_p_i_response`) with `convert_case`. Strips a table of 14 known suffixes (Directories/Templates/Documents/Locales/Dirs/Docs/Assets/Files/etc.) longest-first, then converts the remainder to snake_case. Maps the `case = "..."` attribute value onto a `convert_case::Case`.
