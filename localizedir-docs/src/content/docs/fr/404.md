La page que vous recherchez n'existe pas ou a été déplacée. La documentation de `localizedir` s'organise en quatre sections selon votre objectif :

- **[Démarrage](/fr/tutorials/getting-started/)** — créez votre première énumération localisée, d'une crate vide aux recherches embarquées.
- **[Guides pratiques](/fr/guides/organize-your-directories/)** — résolvez un problème précis : organiser les répertoires, contrôler les noms, gérer les locales inconnues ou corriger une erreur de compilation.
- **[Référence](/fr/reference/attribute/)** — les options exactes de l'attribut, le trait `LocalizeDir`, les conventions de nommage, le catalogue des erreurs de compilation et l'interopérabilité avec `include_dir`.
- **[Explications](/fr/explanation/how-it-works/)** — comprenez l'architecture à intégration unique et ses choix de conception.

Si un lien interne à la documentation vous a mené ici, merci d'[ouvrir un ticket sur GitHub](https://github.com) afin que nous puissions le corriger.
