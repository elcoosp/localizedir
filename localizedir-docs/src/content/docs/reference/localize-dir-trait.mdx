Every enum annotated with `#[localizedir(...)]` implements the `LocalizeDir` trait. Import it alongside the macro:

<Code lang="rust" code={`use localizedir::{LocalizeDir, localizedir};`} />

All trait methods are `const`-cheap: metadata comes from generated string literals and slices, and lookups navigate the embedded directory tree without touching the filesystem.

## Lookups

### try_to_localized_dir

<Code lang="rust" code={`fn try_to_localized_dir(&self, locale: &str) -> Option<&'static Dir<'static>>;`} />

Returns the embedded directory for `locale`, or `None` when the locale is unknown. This is the non-panicking primitive; matching is exact against the locale names discovered at compile time.

<Code lang="rust" code={`let dir = AuthDirs::Welcome.try_to_localized_dir("fr").expect("fr exists");
assert!(dir.get_file("fr/auth/welcome/note.txt").is_some());`} />

The returned reference is `'static` and points into the binary — it lives for the rest of the process with no runtime cost per access.

### to_localized_dir

<Code lang="rust" code={`fn to_localized_dir(&self, locale: &str) -> &'static Dir<'static>;`} />

Panicking convenience wrapper around `try_to_localized_dir`.

- **Without `fallback`**: panics when `locale` has no embedded directory, with a message like ``localizedir: no embedded directory for locale `xx` (variant `welcome`)``.
- **With `fallback = "en"`**: serves the fallback locale's directory when the requested locale is missing; panics only when both are missing, naming the variant, both locales, and the base path.

### full_path

<Code lang="rust" code={`fn full_path(&self, locale: &str) -> std::path::PathBuf;`} />

Composes the embedded path of this variant's directory under `locale`, relative to the embedded root — for example `fr/auth/welcome`. The call is a pure composition: it does not require the locale to exist, and for discovered locales it always equals [`Dir::path()`](https://docs.rs/include_dir/latest/include_dir/struct.Dir.html#method.path) of the directory returned by the lookups.

## Metadata

### available_locales

<Code lang="rust" code={`fn available_locales() -> &'static [&'static str]
where
    Self: Sized;`} />

The locales discovered at compile time under the base path, sorted and de-duplicated. Discovery scans the base path's immediate subdirectories and skips names starting with `.` or `_` plus `node_modules` and `target`.

### has_locale

<Code lang="rust" code={`fn has_locale(locale: &str) -> bool
where
    Self: Sized;`} />

`true` when `locale` was discovered at compile time. Exact match — `"FR"` is not `"fr"`. The default implementation checks membership in `available_locales()`.

### fallback_locale

<Code lang="rust" code={`fn fallback_locale() -> Option<&'static str>
where
    Self: Sized;`} />

The locale configured via `fallback = "..."`, or `None` by default. The generated override exists only when the attribute configures a fallback.

### base_path

<Code lang="rust" code={`fn base_path() -> &'static str
where
    Self: Sized;`} />

The base path exactly as written in the attribute, before `$VAR` interpolation. Useful for diagnostics and for composing file paths in logs.

### parent_folder

<Code lang="rust" code={`fn parent_folder() -> &'static str
where
    Self: Sized;`} />

The parent folder between the locale directory and the variant directories — inferred from the enum name unless overridden with `parent = "..."`.

### dir_name

<Code lang="rust" code={`fn dir_name(&self) -> &'static str;`} />

This variant's directory name in the configured `case` scheme, or the `#[dir_name = "..."]` override.

## Method summary

| Method | Panics? | Returns | Notes |
| :--- | :--- | :--- | :--- |
| `try_to_localized_dir(&self, locale)` | no | `Option<&'static Dir<'static>>` | Core lookup; exact locale match |
| `to_localized_dir(&self, locale)` | yes | `&'static Dir<'static>` | Honors `fallback` when configured |
| `available_locales()` | no | `&'static [&'static str]` | Sorted at compile time |
| `has_locale(locale)` | no | `bool` | Exact match |
| `fallback_locale()` | no | `Option<&'static str>` | `None` unless `fallback` is set |
| `base_path()` | no | `&'static str` | As written in the attribute |
| `parent_folder()` | no | `&'static str` | Inferred or overridden |
| `dir_name(&self)` | no | `&'static str` | Per-variant |
| `full_path(&self, locale)` | no | `std::path::PathBuf` | Root-relative; no existence check |
