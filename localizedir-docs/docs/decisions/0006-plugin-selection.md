# ADR 0005: Plugin selection — what is installed and why the rest are omitted

- **Status:** Accepted
- **Date:** 2026-11-08
- **Context:** Starlight 0.42.10 plugin ecosystem, verified compatible with Astro 7.4.x.

## Installed

| Plugin | Version | Purpose |
| :--- | :--- | :--- |
| `starlight-links-validator` | 0.27.0 | Fails `pnpm build` on broken internal links — a release blocker. |
| `starlight-image-zoom` | 0.16.2 | Click-to-zoom on content images (logo, diagrams). |

## Omitted, with reasons

| Plugin | Reason for omission |
| :--- | :--- |
| `starlight-typedoc` | Generates API reference from **TypeScript** sources. localizedir is a Rust crate; its API reference lives on [docs.rs](https://docs.rs/localizedir) and is hand-curated in this site's Reference section. There is no TypeScript API to generate from. |
| `starlight-openapi` | The project ships no OpenAPI specification to document. |
| `starlight-blog` | The changelog is generated by git-cliff in the source repository and linked from [Release notes](/reference/release-notes/). A second, site-hosted changelog stream would drift from the canonical one. |
| `starlight-versions` | The project has one live version (0.2.x). Versioned docs would add structure without a second line to document. Revisit when a 0.3/1.0 line exists. |
| `starlight-heading-badges` | No page currently needs per-heading badges; the `<Badge>` component covers the inline cases. Avoiding an unused plugin keeps the dependency surface minimal. |

## Also recorded

- **Search** — Pagefind ships with Starlight and is kept as-is (zero config). DocSearch is not added: there is no approved Algolia application for this project.
- **i18n** — a single locale (`root`, `en`) uses Starlight's root-locale convention so translated locale directories can be added later without re-routing URLs.
- **`editLink`** — omitted. The docs site is distributed as a standalone codebase and is not (yet) a directory inside the source repository; an edit link would point at files that do not exist there. Enable `editLink.baseUrl` if/when the site lands under `elcoosp/localizedir`.
- **`llms.txt` / `llms-full.txt`** — generated at build time by `scripts/build-llms.mjs` (runs as part of `pnpm build`) so AI agents can consume the full corpus.
